## 一、先定三件事

|---|---|---|
| 一句话主张 | **一个人的训练档案，一支小队的进步；数据只留在本机。** | v1 讲「今天该不该跑」的个人判断；v2 在个人结论之上，把跑团与远征作为主打的新卖点 |

## 四、画面与动效规范（活泼，但有边界）

1. **弹性只用在 UI 元素上**：卡片、数字、衫位、徽章可做 8% 以内 overshoot 回弹；背景与大结构位移动画不做晃动摇摆。
2. **强调色仍只有蓝 → 青**：亮色只打在当前正在讲的那个数/那一张卡上；状态色按规范：达成绿、提醒琥珀、异常红，不新增第四种强调色。
3. **转场四种**：下压（封面→今日页）、硬切（周视图/玩法快切）、翻牌（衫位/岔路）、飞出（分享卡片）。不用叠化、不用镜头光晕、不用粒子飘散。
4. **前 3 秒就亮产品**：v1 用前 7 秒铺垫问题；v2 节奏快，第 3 秒标志必须完整出现，第 6.5 秒进入数据。
5. **末帧必须可截图**：第 30 秒定格 = 标志 + 主张句 + 三行卖点 + 版本号，四样齐全，能直接当商店首图。
6. **远征与结局表述保持事实口径**：试炼由真实分圈数据核验；结局是赛季判定结果，不做任何超自然解释（沿用设计文档边界）。

## 六、合规与品牌红线（沿用并加严）

- 不出现 Garmin / 佳明、COROS / 高驰 logo，不暗示官方合作；数据源只写「佳明国区 · 高驰」文字。
- 不做医疗表述：不说诊断、治疗、预防伤病；恢复度只描述为训练建议依据。
- 不做绝对承诺：不写「提升成绩 X%」「必破 PB」；所有数字标注为演示数据。
- 不展示异常态：报错卡片、调试 Toast、`0.00 km · 配速 —` 一律不进片。
- 小队口径只说事实：只上传每日里程合计、次数、爬升、500 m 网格编号；轨迹点、配速曲线、心率、位置不上传。
- 静音观看也能看懂：每个结论在画面字幕里自洽，不依赖旁白。
