# 交互树

手机端（WebView + 原生壳）的页面层级、入口归属与返回规则。改 UI 前先对照这里，
避免再出现「同一动作三个入口」「按返回在 tab 之间来回跳」。

## 一、五条硬规则

1. **一级导航只有底部 4 个 tab**，页面内部不再出现指向其它 tab 的链接。
2. **一个动作只有一个入口**（见 §4 唯一入口表），新增入口前先想清楚要不要合并。
3. **二级页只能从所属 tab 下钻**，返回一定回到来源 tab，不横向跳转。
4. **浮层（抽屉 / 弹窗）不进入历史栈**，返回键先关浮层，再谈页面。
5. **同页参数变化用 `replace`**（日期、筛选、翻页），不往历史栈里堆条目。

## 二、结构

```text
RunnerCoach
├─ [tab] 今日  /
│   ├─ 下拉刷新 ────────────── 同步（全局唯一同步入口）
│   ├─ 卡片「导出今日一图流」── 原生：出 PNG 并分享
│   ├─ 卡片「完整看板」─────── 二级页 /view?date=今天&from=today
│   ├─ 今日课表 ────────────── 二级页 /plan?from=today（佳明日历优先，教练计划兜底）
│   ├─ 活动行 ──────────────── 原生：分享脱敏 → 出活动图
│   └─ 最近活动（只读 5 条，不再给「查看全部」——底部有历史 tab）
│
├─ [tab] 历史  /history
│   ├─ 筛选（起止日期 / 类型）── 同页 replace，不压栈
│   ├─ 快捷区间（30/90/365/全部）同页 replace
│   ├─ 分页（加载更早）──────── 同页 replace
│   ├─ 活动行 ──────────────── 原生：出活动图
│   ├─ 按日期看板 ──────────── 二级页 /view?date=…&from=history
│   └─ 补齐历史 ────────────── 无入口：每次刷新后台由近到远自动挪一段
│
├─ [tab] 教练  /ai
│   ├─ 段控：今日 / 体重 / 对话 ─ 同页切换，不写历史、不压栈
│   └─ 齿轮 ────────────────── 模型服务抽屉（全局唯一设置入口，浮层）
│
└─ [tab] 我的  /me
    ├─ 数据源：佳明（直接进佳明登录）/ 高驰（直接进高驰登录）/ 小米体重（面板）
    ├─ AI 模型服务：只读状态一行（入口在教练页齿轮，这里不放链接）
    ├─ 地图底图：已配置 / 未配置（点开填高德 Web 服务 Key，浮层）
    ├─ 素材片段：几段 · 轨迹回放时自动插入（列表 / 相册添加 / 裁剪，浮层）
    ├─ 导出数据：打 zip 进「下载/RunnerCoach」并可直接分享（换机用）
    ├─ 导入数据：选 zip → 二次确认 → 覆盖（先自动备份旧库）
    ├─ 诊断日志：最近异常（可选中复制，浮层）
    ├─ 产物文件 ────────────── 二级页 /files
    └─ 关于 / 隐私说明 ──────── 二级页 /privacy
```

二级页统一带一个「← 返回」到所属 tab：

| 二级页 | 所属 tab | 返回目标 |
|---|---|---|
| `/view?date=…` | 历史 | `/history`（`from=today` 时回 `/`） |
| `/plan` | 今日 | `/` |
| `/files` | 我的 | `/me` |
| `/privacy` | 我的 | `/me` |

## 三、返回键

优先级从高到低，命中即停：

| 当前状态 | 返回行为 |
|---|---|
| 模型服务抽屉打开（`#sheet.on`） | 关闭抽屉，页面不动 |
| 在 `/view` | 回到 `/history`（带 `from=today` 时回 `/`） |
| 在 `/plan` | 回到 `/`（今日） |
| 在 `/files` | 回到 `/me` |
| 在 `/history`、`/ai`、`/me` | 回到 `/`（今日） |
| 在 `/` | 退出 App |

实现方式：页面暴露 `window.__gcBack()` 处理自己的浮层，返回 `true` 表示已消费；
原生只在它返回 `false` 时才做页面级回退。**不使用 `web.canGoBack()` 当唯一依据**，
否则切 tab、翻日期都会在历史栈里来回跳。

## 四、唯一入口表

| 动作 | 唯一入口 | 去掉的重复入口 |
|---|---|---|
| 同步数据 | 今日页下拉 | 顶部 ⟳、我的页「刷新当前页」 |
| 补齐历史 | 无入口（下拉刷新后后台由近到远自动补，进度写在标题栏） | 历史页「补拉历史」、我的页「补拉历史」、今日页快捷卡 |
| 导出今日一图流 | 今日页卡片 | 我的页「导出一图流」 |
| 看完整看板 | 今日页卡片 / 历史页日期 | 看板页顶部「首页」「历史活动」 |
| 模型服务设置 | 教练页齿轮 | 我的页「模型服务设置」（会跳到别的 tab） |
| 小米体重 | 我的页「小米体重」行 | 我的页同名快捷卡 |
| 佳明 / 高驰登录 | 我的页对应数据源行（直达） | 统一的「账号登录」二级选择器 |
| 产物文件 | 我的页「产物文件」 | 产物页「返回首页」 |
| 查看历史活动 | 底部「历史」tab | 今日页「历史活动列表」、看板页「历史活动」 |
| 查看训练计划 | 今日页「今日课表」 | 计划页内的横向 tab 入口 |
| 刷新训练计划 | 计划页「刷新计划」按钮 | 同步时自动拉一次，不额外加入口 |
| 配置地图底图 Key | 我的页「地图底图」 | 活动图里不再放第二处设置入口 |
| 生成轨迹回放视频 | 活动行的分享对话框「回放视频」 | 不再单独做一个 tab |
| 管理素材片段 | 我的页「素材片段」 | 回放对话框里不重复放入口 |

## 五、视觉规范

**深空科技风**：近黑底 + 科技蓝 + 少量辉光。不用纯黑，也不用浅色底 ——
纯黑会让卡片没有层次，浅色底在夜里出图太刺眼。

- 色板只有一处来源：`garmin_cn/ui.py` 的 `CSS` 里的 `:root` 变量；
  `aiui.py` 用同一组色值，原生壳的 `MainActivity` 用同一组 ARGB 常量。
  改色只改这一处，页面、AI 页、原生外壳三边同时生效。
- 背景 `#070B12`；卡片 `#0F1622`，次层 `#131C2B`；
  边框 `rgba(96,165,250,.16)`，分隔线 `rgba(96,165,250,.09)`。
- 正文 `#E8F0FB`，次要 `#B7C7DD`，弱化 `#7C8FA8`，最弱 `#4E6076`。
- 主色 `#3B82F6`（科技蓝），浅底 `rgba(59,130,246,.14)`，亮字 `#8CC2FF`；
  辅助青 `#22D3EE`、琥珀 `#F5A524`（仅用于提醒）、红 `#F2555A`（仅用于异常）。
- 辉光统一走 `--glow`（`0 0 0 1px rgba(96,165,250,.10), 0 10px 30px -16px rgba(59,130,246,.55)`），
  不要每个卡片自己写一套 `box-shadow`。
- 圆角 `--r: 16px`（卡片）、行 14px、按钮胶囊；数字统一 `tabular-nums`。
- 底部导航：选中项 = 蓝色图标文字 + 蓝色浅底块；未选中 = `--muted`，不加背景。
- **硬指标（`tools/audit_ui.py` 会量）**：最小字号 11px；可点元素高度 ≥40px
  （主按钮 44px）；`--faint` 在卡片底上的对比度 ≥4.5:1；360/390/430 三档宽度
  不允许横向溢出；关键数值不允许被 ellipsis 截断。
- 状态色：**达成/良好 = 绿（`--ok`），异常 = 红（`--bad`），注意 = 琥珀（`--warn`）**。
  不要套 A 股涨红跌绿——这里讲的是训练状态，不是行情。
- 背景辉光用 `body::before` 固定伪元素，**不要** `background-attachment:fixed`
  （WebView 每次滚动会重绘整面）。
