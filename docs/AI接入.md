# AI 教练：模型服务接入指南

RunnerCoach 的 AI 功能有三块，都由一个模型驱动：

| 功能 | 入口 | 回答什么 |
|---|---|---|
| **今日建议** | AI 教练页「今日」/ 看板右上角 | 今天怎么练、做什么、别做什么、为什么 |
| **体重复盘** | AI 教练页「体重」 | 趋势判断、减脂速率是否合理、吃法建议 |
| **对话** | AI 教练页「对话」 | 带着当天数据回答你的具体问题 |
| **训练解读** | 「今日」页底部按钮 | 单次活动的质量分析与下次改进 |

## 数据纪律（写进系统提示词的）

模型只依据本地算好的数据说话：恢复度、睡眠、训练负荷、体重趋势、
备赛课表都由规则引擎先算好再交给模型解释。**模型不决定训练量**——
处方来自 `coach.py` 的规则引擎，AI 负责讲清楚理由和风险。

## 两种接入方式

App → 菜单 → 模型服务设置，两种模式二选一：

### 1. 自配 API（数据只发给模型商）

| 预设 | 地址 | 默认模型 | 备注 |
|---|---|---|---|
| DeepSeek | api.deepseek.com | deepseek-chat | 推荐：便宜、中文好、直连稳 |
| 通义千问 | dashscope.aliyuncs.com | qwen-plus | 新用户有免费额度 |
| Kimi | api.moonshot.cn | moonshot-v1-8k | 长上下文 |
| 智谱 GLM | open.bigmodel.cn | glm-4-flash | 有免费档 |
| OpenAI | api.openai.com | gpt-4o-mini | 需要网络出口 |
| 本地 Ollama | 127.0.0.1:11434 | qwen2.5:7b | 完全离线 |
| 自定义 | 自己填 | 自己填 | 任意 OpenAI 兼容服务 |

key 只存本机 `data/llm_config.json`（权限 600），不上传、不写日志。

一次调用的成本量级：今日建议约 3~5k token ≈ 0.01~0.02 元（DeepSeek 价格）。
同一天的今日建议有缓存，反复打开不重复计费。

### 2. 平台额度（走你自己的网关）

适合把 AI 能力分享给别人用、或想统一计费：App 只拿设备令牌，
真正的上游 Key 在网关上，按 token 扣余额，兑换码充值。

- 网关代码在 `server/`，部署见 `server/deploy.md`（纯标准库，`python app.py` 即跑）
- App 侧：填平台地址 → 点「绑定本机」→ 显示余额 → 输兑换码充值
- 管理员：`POST /admin/codes` 批量生成兑换码，`GET /admin/accounts` 对账

## 桌面端

```
python cli.py ai            # 起服务并打开 AI 教练页
python cli.py ai --model mock   # 本地假模型调试界面，不花钱
```

手机浏览器也能用：`python cli.py serve --lan` 后访问
`http://电脑IP:端口/ai`——但 AI 接口只允许本机调用，局域网访客只能看
看板，不能调 AI（花钱和发数据的通道不给外部）。

## 隐私边界

- AI 功能会把**你当天的训练与身体数据**（恢复度、睡眠、配速、体重趋势）
  发给你选择的模型服务商——自配时发给它，平台模式时发给网关再转上游。
- 不发送：姓名、邮箱、位置、原始轨迹坐标。
- 完全离线的替代：选「本地 Ollama」，数据不出本机。

## 代码结构

| 文件 | 职责 |
|---|---|
| `garmin_cn/llm.py` | 协议层：OpenAI 兼容调用、配置读写、余额/兑换、错误分类 |
| `garmin_cn/aicoach.py` | 业务层：三个场景的提示词、结构化输出解析、缓存 |
| `garmin_cn/aiapi.py` | 接口层：动作名 → 数据，HTTP 与原生桥共用 |
| `garmin_cn/aiui.py` | UI：单文件 HTML（无外部依赖），fetch 同源 `/ai/*` |
| `garmin_cn/serve.py` | 本地服务：新增 `/ai` 页面与 `/ai/*` POST（仅回环） |
| `server/app.py` | 平台网关：余额/兑换码/计费/转发（部署在你自己的服务器） |
| `tools/mock_llm.py` | 本地假模型：调试 UI 不花钱 |
