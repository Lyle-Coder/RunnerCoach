# 文案规范

界面上的字只做两件事：说清是什么、说清怎么做。**不解释为什么这么设计。**

## 五条

1. **一句话一件事。** 能删的字都删。删掉「其实、说白了、换句话说、这样一来、需要说明的是」。
2. **不用破折号补解释。** `A —— B` 里的 B 通常是自我辩解。要么删掉，要么另起一句。
3. **不用「不是……而是……」。** 直接说是什么，不先说它不是什么。
4. **一个东西一个叫法。** 衫/称号、轨迹/轨迹形状、小组/组，全站统一，不要一句里换三个说法。
5. **空态只写「为什么空 + 下一步」，最多两句。** 不写「这里会亮起来」「不会悄悄消失」这类文学表达。

## 检查

```
python tools/text_audit.py            # 全部
python tools/text_audit.py --file garmin_cn/groupui.py
```

脚本只扫**字符串字面量**（注释和 docstring 不算），按破折号、不是…而是、说白了、
怎么来的、因为/所以、请/注意 等规则列出来。命中不等于必须改，逐条判断：

- **保留**：玩法规则、隐私口径（上传什么/不上传什么）、操作路径（点哪里）、
  计分与门槛（数字必须来自服务端）。
- **改**：解释设计意图的、重复上文的、自问自答的、用比喻代替事实的。

## 已知不做

- `aicoach.py` / `nutrition.py` / `posture.py` 里的 prompt 不给用户看，不按这套改。
- `selftest.py` 的断言消息是给开发看的，不改。
- CSS / SQL 里的注释不扫。
