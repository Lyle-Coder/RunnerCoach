# 跑步与骑行适配

源码分支：`codex/cycling-parity`。本次不修改发布版本号；安装包需要另行构建和真机验收。

## 使用入口

「我的 → 运动设置」可选择主要运动，以及跑步／骑行各自的最大心率、阈值心率、心率区间名称。骑行另有 FTP 和本地训练模板（有氧、恢复、功率间歇）。留空不会自动猜测 FTP。训练计划页展示骑行的逐步用时和功率目标。

「历史」增加跑步、骑行、全部运动切换，活动列表及周／月／年统计使用同一筛选。跳转月份和周期明细时保留运动类型。骑行均速使用 km/h，踏频使用 rpm；跑步继续使用每公里配速和 spm。

## 完成度

当天有活动只证明练过，不证明完成课表。只有运动类型匹配且达到目标的 90% 才算完成：有距离目标优先检查距离，否则检查用时。一天排了多个运动项目时，每个项目都要满足要求。无运动类型的旧课表不会用其他运动补足证据；需要重新读取课程或同步完整记录。

越野跑、跑步机、跑道跑等统一归跑步；公路、山地、碎石和室内骑行等统一归骑行。骑行时长不会再抵扣跑步目标。

## 功率与缓存

佳明读取骑行踏频通道，保留 0 rpm，不做跑步单侧步频翻倍，也不生成步幅。高驰骑行保留原生踏频、功率，去掉步幅语义。

功率均值、NP、机械功和功率分布在时序抽稀前计算。0 W 是有效数据，缺测不是 0 W；超过 5 秒的传感器间隔不补值，NP 的连续 30 秒窗口会在缺测处中断。功率覆盖不足 90% 不计算 TSS；没有 FTP 时不计算 IF/TSS。功率间歇按反复的工作／恢复功率段识别，室内无距离也可识别，不用骑行速度起伏推断间歇。

NP 采用 30 秒滚动均值的四次方均值再开四次方根，IF = NP / FTP，TSS = 小时数 × IF² × 100。参考 [TrainingPeaks 的 NP 说明](https://www.trainingpeaks.com/coach-blog/normalized-power-how-coaches-use/) 和 [TSS 说明](https://www.trainingpeaks.com/learn/articles/estimating-training-stress-score-tss/)。结果是本地计算值；暂停处理、采样频率和设备算法可能使其与设备显示不同。

历史活动使用当前 FTP 复算 IF/TSS 和功率分区，不声称使用了活动当时的 FTP。旧佳明骑行缓存有机会联网时升级，离线保留已有内容；缺失的传感器通道无法从旧缓存恢复。高驰缓存版本升级为 13，首次读取旧缓存需要联网补抓。

## 共享数据与负荷

睡眠、HRV、静息心率、体重、饮食仍属于同一个运动者，继续共用。活动保持来源与运动类型，跨来源去重不会合并跑步与骑行。

App 的综合 CTL／ATL／TSB／ACWR 改为统一心率 TRIMP，使用各项目最大心率配置；未设置时沿用默认 190。设备原始负荷留在活动记录中，骑行 TSS 独立展示，不与 TRIMP 直接相加。缺心率活动未计入 TRIMP，并显示数据不完整提醒；训练时长仍正常计入。负荷窗口补齐连续日期，使用至少 84 天历史；同时输出跑步和骑行各自的负荷与时长。与旧版相比，统一口径后数值会变化，不能沿用旧版数值直接比较。

设备提供的心率分区时长保持原始边界，不用本地设置重新解释为另一套分区；运动设置仅允许按项目覆盖显示名称。现有上游日汇总 VO₂max 没有可靠的运动类型标记，保留为“未分项”，不将其冒充骑行专项指标，也不合成不存在的骑行 VO₂max。

运动设置会作为不含账号、密码的 `extras/sports.json` 随数据包导出和导入，保留目标设备其他配置。

## 训练和 AI

主要运动选骑行时，本地兜底生成骑行课程，不自动套用 105K 跑步课表。功率间歇模板需要设置 FTP，恢复度和疲劳状态不满足条件时退为恢复／有氧模板。已有佳明日历课表仍优先显示。

AI 上下文包含运动类型、正确单位、功率覆盖、NP／IF／TSS、功率间歇和分项目负荷。骑行不再传递跑步配速，也不要求模型分析跑步步幅；不默认用户备战 105K。

桌面端支持 `run.bat push --sport bike --date YYYY-MM-DD --dry-run` 预览单日骑行课程 JSON；去掉 `--dry-run` 才会通过现有佳明创建／排程通路推送。骑行 DTO 使用瓦数功率目标，不使用跑步配速转换；枚举参考 [python-garminconnect 的训练课程模型](https://github.com/cyberjunky/python-garminconnect/blob/master/garminconnect/workout.py)。不允许用骑行分支批量替换跑步课程。

真实佳明／高驰骑行文件、设备课程同步及安卓原生导出仍需设备账号和真机验收。现有桌面跑步推送通路保持原状。
