# 隐私说明

> 与 App 内「我的 → 关于 → 完整隐私说明」同一个口径。改一处请同步另一处
> （App 内那份在 `garmin_cn/ui.py` 的 `privacy_page()`）。

## 收集

**不收集。** 没有账号体系、没有遥测、没有崩溃上报。诊断日志只写在这台设备上，
发不发由用户决定。

## 存在哪里

日汇总、活动、明细、体成分、素材清单都存在 App 私有目录的 SQLite 里，
卸载即清空。账号密码不进数据库：会话保存在私有目录，安卓版的密码放在系统 Keystore。

## 什么时候出网

只有三类请求，且都由用户主动触发：

1. **官方接口**：佳明国区（`connect.garmin.cn`）、高驰、小米健康云，用用户自己的账号登录后同步；
2. **AI 服务**（可选）：用户自己填 `base_url` 与 key，提问内容直连所选服务商；
3. **高德底图**（可选）：只请求地图瓦片，用于活动图与回放底图。

没有中间服务器，任何数据都不经过本项目作者。桌面端 `serve --lan` 只在本机/局域网，
带访问码，不上公网。

## 分享前

活动图与轨迹回放**包含 GPS 轨迹**，起终点可能暴露住址。出图前会先问脱敏档位：

- `trim`（默认）：裁掉首尾各 200 m
- `hide`：完全隐藏轨迹

脱敏在生成产物之前完成，产物里不留原始折线。

## 不会做的事

- 不做代登录服务（佳明条款不允许把凭据交给第三方）；
- 不把任何数据托管到服务器，不做商业托管；
- 不转卖数据、不用于训练模型。

## 怎么删

- 卸载 App（或删除项目目录下的 `data/`）；
- 用「我的 → 导入数据」覆盖成一份空库/旧库（覆盖前会自动备份，备份文件在 `data/` 下，自己删）；
- 撤销官方授权：到佳明/高驰/小米的账号安全页移除设备或改密码。
