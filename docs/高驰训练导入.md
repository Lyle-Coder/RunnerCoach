# 高驰跑步与骑行训练导入

通过官方 MCP，将本地生成的单次训练保存到高驰训练库，或直接安排到指定日期。训练到达高驰账户后，打开高驰 App 同步到手表或码表。本 App 不直接连接设备蓝牙。

## App 入口

「训练计划 → 导入本地训练到高驰」，或「我的 → 高驰训练」。

1. 选择跑步、骑行或跟随运动设置。
2. 选择本地课表日期。恢复度建议只能从今日生成；其它日期须有已配置的本地备赛课。
3. 选择训练库或安排日期。当前官方单次训练日历接口允许今天至未来 90 天，日期最终按高驰账户时区校验；不要与长期训练计划的 14 天开始窗口混淆。
4. 先预览距离/时间、重复组及强度，再点击「导入高驰」。未授权时可在同页完成官方授权，授权后需重新预览。
5. 页面显示「已核验」表示已从高驰回读并核对课程内容；设备端仍需通过高驰 App 同步。

## 支持的训练内容

| 内容 | 导入行为 |
| --- | --- |
| 跑步备赛课 | 沿用本地生成器的热身、主课、恢复、放松和重复组 |
| 配速目标 | 从原生成器的 m/s 转成高驰的整数秒/公里 |
| 心率目标 | 保留 bpm 绝对区间 |
| 骑行模板 | 保留各段时间，使用预览时 FTP 换算后的瓦数目标 |
| 按计圈键结束 | 保留为手动结束，不自动替换为时间 |
| 无明确强度的建议、未设置 FTP 的骑行 | 明确勾选「不设置强度提醒」才可仅导入时间/距离和文字说明 |
| 同日力量加跑步 | 仅导入跑步，预览明确提示力量部分不支持 |
| 不支持的结束条件或嵌套重复组 | 拒绝导入，不自动修改训练内容 |

预览针对本地生成内容，不会根据佳明日历中的课程标题猜测间歇结构。高驰越野跑模式不支持按时间结束步骤，这类内容会明确报错；当前本地山地跑课沿用原生成器的跑步模式。

## 命令行

原有佳明默认行为保持不变；高驰需要指定 `--target coros`。

```bat
run.bat coros mcp-login
run.bat push --target coros --sport run --date YYYY-MM-DD --dry-run --verbose
run.bat push --target coros --sport run --date YYYY-MM-DD
run.bat push --target coros --sport bike --date YYYY-MM-DD --dry-run --verbose
run.bat push --target coros --sport bike --date YYYY-MM-DD --library
```

`YYYY-MM-DD` 请替换为实际日期；骑行恢复度建议只支持今日。跑步可用已有 `--week` / `--start` / `--end` / `--all` 逐日导入本地备赛课程，全部日期与课程会在写入前校验。批量导入是多节单次课程，不会创建高驰的 4–16 周训练计划对象。高驰不支持 `--replace` 删除重建。

`--library` 只存训练库，不排日历；`--no-intensity` 明确移除强度提醒；`--dry-run` 不联网提交、不读取高驰训练数据。

## 重复保护与恢复

- 提交前冻结预览内容，并先在本机 SQLite 记录操作，再调用高驰。
- 相同授权下，同一课程、同一位置/日期不会重复创建。
- 超时、连接中断、返回不完整时，状态为「待核对」，不会自动重发。使用预览页的「检查导入结果」，或「最近导入 → 核对这条记录」只读查询；重启后仍保留记录。
- 只在高驰回读的课程名称、说明、运动类型及全部步骤与预览一致时标记「已核验」。课程库与日历副本分别核验。
- 仍无法确认时到高驰 App 核对。删除、移期及修改已有课程在高驰 App 完成；此入口只新增所选课程，不覆盖已有训练。
- 去重记录保存在 `data/coros_workouts.sqlite3`，绑定本次授权，不包含访问令牌。重新授权、换设备或删除本地数据后，需先在高驰 App 检查是否已存在，避免再次导入。
- OAuth 凭据在 `data/coros_mcp.json`，不提交 Git、不进入数据导出包。只有用户点击导入，所选课程才会发送到高驰。

2026-11-13 使用已授权账号读取实际 `tools/list` 并校验嵌套字段；两节用户许可的验证课程已成功存入训练库，并回读核对：

- 跑步训练导入验证：1 分钟，6:00–7:00/km。
- 骑行训练导入验证：1 分钟，100–120 W。

验证课程没有安排日期。日历创建、重复组等由离线模拟服务覆盖，尚未进行真实日历写入或设备端执行验证。
